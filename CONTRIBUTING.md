# Contributing

This project is licensed under the [HGL General License](https://evgnomon.org/docs/hgl). All contributions are accepted under the same license.

## Sign-off

Every commit must include a `Signed-off-by` line certifying the Developer Certificate of Origin (https://developercertificate.org):

```bash
git commit -s
```

This certifies you wrote the contribution or have the right to submit it under HGL. It does not transfer copyright — you keep it.

## Attribution

Contributors are credited in the `AUTHORS` file, generated from git history, rather than in individual source file headers. By contributing you agree to attribution in this form. If you would like to be credited under a different name or email, edit `AUTHORS` in your pull request.

## File headers

Source files carry only:

```text
License-Identifier: HGL
Copyright (C)
```
