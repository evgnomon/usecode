# Contributing

This project is licensed under the [HGL General License](https://evgnomon.org/docs/hgl). All contributions are accepted under the same license.

Participation in this project is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Sign-off

Every commit must include a `Signed-off-by` line certifying the [Developer Certificate of Origin](DCO):

```bash
git commit -s
```

This certifies you wrote the contribution or have the right to submit it under HGL. It does not transfer copyright — you keep it.

For this project, "open source license" in the DCO means the [HGL General License](https://evgnomon.org/docs/hgl).

## Attribution

Contributors are credited in the `AUTHORS` file rather than in individual source file headers. By contributing you agree to attribution in this form. New authors are added at the end of `AUTHORS`, one per line as `Name <email>`, matching the name and email of their commits in git history. Existing entries are never modified.

## File headers

Source files carry only:

```text
License-Identifier: HGL
Copyright (C) The Usecode Authors (see AUTHORS)
```
